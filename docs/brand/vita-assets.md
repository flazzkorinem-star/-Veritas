# 维塔资产说明

## 原创身份锁

维塔是一只沉静的卡皮巴拉学习伙伴。造型使用真实卡皮巴拉偏低长的体态、钝方口鼻、小圆耳和克制表情，不穿服饰，不携带相机、帽子、围巾或背包。后侧固定保留三道浅色“知识涟漪”纹，作为七种状态共享的唯一识别标记。

插画使用平涂水粉、轻微纸张颗粒和清晰墨线。角色主色为可可棕与燕麦色；状态道具只使用 Veritas 的深青、芥黄与珊瑚色。角色不跳跃、不高频抖动，也不使用羞辱、惊吓或夸张兴奋的表情。

## 七种状态

| 状态     | 文件                            | 动作                       |
| -------- | ------------------------------- | -------------------------- |
| 默认     | `public/vita/default.png`       | 安静坐姿，双爪自然相合     |
| 等待上传 | `public/vita/waiting.png`       | 双爪接住一张空白材料       |
| 处理中   | `public/vita/processing.png`    | 专注整理三张空白材料       |
| 给提示   | `public/vita/hint.png`          | 托起一枚两叶小芽           |
| 鼓励     | `public/vita/encouragement.png` | 手放心口，轻轻挥手         |
| 展示答案 | `public/vita/answer.png`        | 展开一本无文字的空白册页   |
| 错误     | `public/vita/error.png`         | 平静查看折角材料，准备重试 |

## 生成与处理

资产使用 Codex 内置 `imagegen` 生成。默认态提示固定体态、五官、色板、媒介、三道涟漪纹和禁止项；其余六态都以默认态为唯一身份锚点，只修改上述动作。每张底稿使用纯品红背景，经技能自带的 `remove_chroma_key.py` 做软边缘、去溢色和透明化处理。

七张成品均为 1254×1254 RGBA PNG，四角完全透明，主体边界经过逐张检查。项目不保留品红中间副本；原始生成结果仍保留在 Codex 生成目录中。
