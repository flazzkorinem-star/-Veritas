# Vita 视觉资产

## 角色母版

维塔是一只专业、亲切、活泼的卡皮巴拉学习伙伴。`references/vita-final-reference.png` 是角色造型、服装、面部比例、品牌符号、关键动作和聊天头像的最终权威来源。旧有探索图与二次生成图不再决定最终形象。

角色固定使用暖棕毛色、奶油色面颊、深可可轮廓、浅鼠尾草绿外套、奶油色小背包和橙色星星挂件；胸前与背包上的品牌符号固定为橙色描边的“打开的书 + 小芽”。所有状态使用同一头身比例、五官、服装和配件，缩小到聊天头像尺寸时仍能读出表情。

插画使用温暖手绘质感、柔和纸张颗粒和低饱和色彩。动作可以有轻微弹性、幽默和独立情绪，但不高频跳动，不使用羞辱、惊吓或失控兴奋的表情。

## 七种状态

| 状态     | 文件                                  | 动作                   |
| -------- | ------------------------------------- | ---------------------- |
| 默认     | `public/vita/default-final.png`       | 自然微笑正面站立       |
| 等待上传 | `public/vita/waiting-hd.png`          | 开心挥手欢迎用户       |
| 处理中   | `public/vita/processing-final.png`    | 低头整理三张知识卡片   |
| 给提示   | `public/vita/hint-final.png`          | 举起一根手指给出提示   |
| 鼓励     | `public/vita/encouragement-final.png` | 竖起拇指肯定用户       |
| 展示答案 | `public/vita/answer-final.png`        | 拿着打开的书自然讲解   |
| 错误     | `public/vita/error-full.png`          | 轻微惊讶并准备一起重试 |

聊天头像使用同名的 `*-avatar-final.png` 近景资产，直接从最终设定图的“聊天头像”区域提取；头像保留同一五官和外套领口，不再用全身图缩小代替。

`waiting-hd.png` 和 `error-full.png` 是空状态使用的高清全身图，避免小尺寸裁图放大后模糊或截断。

## 资产来源

`*-final.png` 动作、聊天头像和品牌符号直接从最终设定图提取。`waiting-hd.png` 与 `error-full.png` 不来自母版裁切，而是为大尺寸空状态制作的独立高清补稿；这是当前运行时资产的两项例外，只继承母版造型，不作为新的角色设定来源。

`*-final.png` 动作使用透明背景。`waiting-hd.png` 与 `error-full.png` 保留浅色纸张背景，不含透明通道。聊天头像保留母版圆形近景，由界面做圆形裁切。

`public/vita/` 只保留当前运行时使用的七种动作和七个头像。探索稿、旧导出版本和重复文件不进入主工作树。
