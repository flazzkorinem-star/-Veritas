## 每个 Session 的最低完成条件

1. 通过网页上传材料并等待 Agent 1、首问完成；
2. 记录材料判断、首问、主题数量和首个主题名称；
3. 按案例脚本进行至少一次 Agent 2 对话；
4. 通过真实作答、提示或答案走完当前主题四层；
5. 记录每轮前后可见分数、主题状态、按钮状态和材料进度；
6. 等待 Agent 3 报告生成并保存报告全文；
7. 检查控制台错误与 Agent 请求失败；
8. 按产品定义给出 PASS、PARTIAL 或 FAIL，并记录可复核理由。
