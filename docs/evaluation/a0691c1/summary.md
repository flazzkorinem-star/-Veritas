# Veritas a0691c1 真实用户评测总结

## 结论

Veritas 的通用对话与确定性状态边界已经形成可用基础：解释、写作、换话题、语义提示、语义答案、主题切换、刷新恢复和两类提示注入均能完成，20 条正式 session 的 253 次 Agent API 操作全部为 200，浏览器控制台问题为 0。

但当前版本不应被描述为“评测全面通过”。三项核心问题仍影响发布质量：首问与记忆层大面积错位、连续无进展与照抄分类分别失败、Agent 3 在混合对话报告中生成了没有证据支持的具体盲点。此外，所有下载 Markdown 都暴露内部状态枚举。

## 范围

- 20 个相互隔离的本地生产 Edge 学习 session；
- 每条从真实网页文件上传开始；
- 每条至少完成当前主题的四层，触发提示或答案并生成 Agent 3 报告；
- 多主题材料如实停留在任务 `IN_PROGRESS`，报告显示已完成 1 / 总主题数，不冒充整份完成；
- 覆盖正常、部分正确、误解、不知道、照抄、暂停、通用写作、语义提示、语义答案、目标变化、换话题、主题切换、刷新、材料注入、用户越权和混合报告证据。

## 三个 Agent 的总体评价

### Agent 1：4 / 5

- 20 / 20 材料通过真实提取与覆盖审计；
- 所有核心条目都恰好归入一个诊断主题，所有条目均有来源；
- ETF、城市内涝、水循环、光合作用和考试代码价值均保留了核心语义；
- 同一材料的节点数量存在 1/2 的波动，但没有发现确定性覆盖丢失，因此列为稳定性观察项。

### Agent 2：3 / 5

- 通用对话、语义提示/答案、安全拒绝和状态保持表现稳定；
- 部分正确和误解纠正案例表现好；
- 15 / 20 首问与 MEMORY 目标明显不一致；
- 9 次出现同轮双问题；
- 连续无进展、照抄、学习目标持久化三个专项目标未达成。

### Agent 3：4 / 5

- 20 / 20 引文均真实存在且角色为 USER；
- 报告进度与最终 session 状态 20 / 20 一致；
- 能排除普通写作、越权请求和答案请求作为掌握证据；
- S20 出现无证据支持的具体盲点，说明自由文本结论仍缺少事实引用边界；
- Markdown 渲染 20 / 20 暴露内部枚举，属于确定性报告逻辑缺陷。

## 归因分布

- Prompt / 操作契约：首问层级、双问题、暂停请求执行；
- 上下文：显式学习目标未持久化；
- Agent 判断：无进展、照抄、目标提炼、部分材料扩展边界；
- 状态机：没有发现 reducer 自身非法转移；S12 是上游未产生状态事件；
- 报告逻辑：无证据盲点和 Markdown 枚举泄漏。

## 发布判断

当前评测门槛为“不通过，需要修复后回归”，原因不是网络或链路稳定性，而是三个目标案例明确 FAIL，以及一项 20 / 20 的报告下载缺陷。安全硬边界本轮通过：没有提示注入成功、状态越权、秘密泄漏或伪造用户引文。

建议修复顺序：

1. 先修 Agent 3 盲点证据引用和 Markdown 状态映射，恢复报告可信度；
2. 修首问 MEMORY 对齐与同轮唯一主问题；
3. 修 `NO_ANSWER/STALLED` 和 `COPIED` 判断；
4. 修学习目标结构化更新；
5. 用本评测集原样回归，不为单句样例增加特例。

## 长期持续评测

1. 将 S01—S20 冻结为 v1 人工黄金集，不修改旧输入来迁就修复；新增变体使用新 ID。
2. 每个相关 Prompt、schema、状态或报告改动至少回归受影响 bad case、相邻正常案例和一个高风险案例。
3. 核心随机性案例每版运行 3 次，报告单次结果和稳定通过率，不只挑最好的一次。
4. 发布门槛：硬性失败 0；目标 FAIL 0；首问层级对齐不低于 90%；双问题 0；报告引文和进度 100% 合法；Markdown 内部枚举 0。
5. 真实使用产生的新 bad case 必须记录材料、完整上下文、实际输出、期望、根因、修复和回归，不把人工预设包装成线上案例。
6. 黄金案例和人工评分稳定后再校准 AI Judge；AI Judge 只能提效，不能替代事实校验和人工最终判断。

## 限制

- 这是本地桌面 Edge、Markdown 材料和单一人工评审的评测，不代表所有文件格式、移动端和语音能力已在本轮重新覆盖；这些已有独立工程验收，但不计入本轮 20 条产品语义分母。
- 多数 session 为人工预设，而非线上真实用户日志；所有预设来源均已明确标记。
- 动态问题会变化。S03 证明固定回答可能不匹配随机首问，因此后续正常路径应使用人工实时作答或问题条件化答案，不用固定文本硬套。
- 20 条可以发现高价值问题，但不足以给模型总体能力下统计学结论；应持续回流真实使用案例。
