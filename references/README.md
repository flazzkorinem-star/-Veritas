# Veritas 视觉参考说明

本目录只用于保存产品讨论中的参考资料，避免原始聊天附件或临时文件在新窗口中丢失。

## 文件用途

- `early-layout-draft.png`：早期 Veritas 分区草图。只保留“工作区 / 节点列表与对话 / 诊断区”的信息架构意图，具体布局、组件、颜色和视觉细节都需要重新设计。
- `pc-wechat-layout-reference.png`：只参考 PC 即时通讯产品中“对象列表 + 单对象聊天”的交互心智，不复制微信的界面、图标、颜色或组件细节。
- `mascot-style-reference.jpg`：只参考圆润、亲和、适合延展表情与动作的商业插画气质。Veritas 必须生成原创的卡皮巴拉“维塔”，不得临摹参考角色的造型、服饰、配色或识别性细节。

## 使用红线

1. 参考图不是 UI 还原目标，也不是设计稿。
2. 不复制任何第三方品牌资产、角色造型、组件结构或标志性配色。
3. 最终页面以 `DESIGN_GUIDE.md` 的原创视觉系统为唯一依据。
