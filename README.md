# Veritas

Veritas 是一个提前掌握材料、学习目标和学习进度的通用 AI 学习伙伴。它面向已经学过一份材料、想确认自己到底懂没懂、哪里有遗漏并把遗漏学会的人。用户上传材料后，维塔先判断材料重点并提出一道有价值的问题；用户也可以随时讨论、追问、解释、整理或处理别的任务，只有真正回答当前问题的消息才会进入记忆、理解、应用和分析四层诊断。

项目当前只面向本地单用户场景，不部署公网。模型统一使用 `deepseek-v4-flash`，原始文件、任务状态和聊天历史保存在当前浏览器的 IndexedDB 中。

## 核心能力

- 支持 PDF、DOCX、PPTX、Markdown、TXT、PNG、JPG/JPEG 和 WebP；图片与扫描 PDF 使用本地 OCR。
- Agent 1 建立可追溯且关注学习价值的知识地图，Agent 2 是直接和用户对话的通用 Vita，Agent 3 生成忠实的任务级报告。
- 材料是 Vita 的背景，不是能力围栏；普通对话不会被强行改造成测验，也不会改变诊断状态。
- 上传完成后直接保留当前主问题、提示和答案入口；用户临时换话题后仍可回来继续。
- 四层顺序、状态转移、计分、完成和持久化全部由确定性代码控制，模型不能直接改状态。
- 每个主题保留独立聊天、主问题、提示、得分和完成状态；刷新或重新打开同一浏览器后可以恢复。
- 支持文字回答、浏览器中文语音转写、三级提示、查看答案和低干扰的下一主题导航；在输入框中自然提出提示或答案请求，也会复用同一流程。
- 连续三轮没有进展时，Vita 会讲清当前答案并留在同一层，改用一道更小的同目标问题验证；只有验证答对后才进入下一层。
- 用户补充学习目标后，后续解释和问题场景会随之调整，尚未开始的主题也可按新目标重新排序；已开始与已完成结果不变。
- 报告支持 Markdown 下载、打印或保存为 PDF，以及系统分享或复制摘要回退。
- 工作区支持搜索、重命名、置顶、分享、删除和六秒内撤销删除。
- 桌面、平板、手机竖屏和手机横屏均有真实 Edge 验收。

## 快速开始

### 1. 准备环境

- Node.js `20.9.0` 或更高版本；
- npm；
- Microsoft Edge 或其他基于 Chromium 的现代浏览器；
- 可用的 DeepSeek API Key。

### 2. 安装依赖

```bash
npm ci
```

### 3. 配置本地密钥

复制 `.env.example` 为 `.env.local`，然后只在本机填写：

```text
DEEPSEEK_API_KEY=你的本地开发密钥
```

不要把 `.env.local`、密钥值、密钥片段或哈希提交到 Git、聊天、日志、截图和测试产物中。

### 4. 启动开发环境

```bash
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。

### 5. 运行本地生产构建

```bash
npm run build
npm start
```

## 使用方式

1. 在空工作区上传一份材料。
2. 等待本地解析、必要时 OCR、紧凑知识编译和首个问题完成；对不超过 5 MB 且解析后不超过 30 万字符的文本型 PDF、DOCX、PPTX，目标是在 3 分钟内完成，期间可以取消，失败或刷新中断后可以重新处理。扫描 PDF 与图片属于单独的 OCR 慢路径。
3. 回答当前问题，或用文字、语音继续提问、讨论、整理内容并告诉 Vita 你的学习目标；普通对话不会让当前问题消失或被误评分。
4. 需要帮助时可以点击提示或答案，也可以直接在输入框里自然提出请求。
5. 主动查看答案会直接进入下一层并记为“看过答案但未验证”；自动讲解则会先用同层小题确认是否学会。
6. 完成当前主题后继续对话、切换主题，或在诊断区查看和导出整份材料的学习报告。

单文件最大 30 MB；PDF/PPTX 最多 200 页或幻灯片，扫描 PDF 最多 OCR 50 页，图片最多 4000 万像素。只支持现代 `.docx` 与 `.pptx`，不支持旧版 `.doc` 与 `.ppt`。

## 架构与边界

```text
浏览器文件解析与 OCR
  → 同源 Agent API
  → 并行紧凑提取与分层归并
  → 固定 DeepSeek V4 Flash 调用
  → Zod 输出校验
  → 确定性状态机与 IndexedDB 事务
  → React 纯文本界面与任务级报告
```

- 浏览器负责文件校验、解析、OCR、界面和本地数据；大型格式解析器按需加载。
- 同源 `/api/agents` 路由负责来源、格式、体积、频率和并发限制，并在服务端读取密钥。
- 三个运行时 Agent 没有代码执行、文件系统、环境变量或任意网络工具。
- 材料、用户消息和模型输出均视为不可信数据；所有模型结构化输出必须通过严格 Zod 校验。
- 报告会结合用户与 Vita 的有序对话，区分原本就会、提示或引导后通过、讲解后验证学会、看过答案但未验证、仍有误解和尚未诊断的范围；分数、层级状态、原话、来源和 Markdown 仍由本地代码核验。

更完整的产品事实、安全边界和代码职责分别见 [DESIGN_GUIDE.md](DESIGN_GUIDE.md)、[SECURITY.md](SECURITY.md) 和 [PROJECT_MAP.md](PROJECT_MAP.md)。

## 数据与隐私

- 原始文件不会永久上传服务器，保存在当前浏览器 IndexedDB。
- 为生成知识地图，解析文本会按受字节预算约束的来源分片发送给 DeepSeek；归并只发送紧凑候选和来源 ID，不再次发送原文。对话和报告只发送当前需要的结构化材料上下文、学习目标、进度与相关聊天，本地服务端不保存材料和聊天。
- 浏览器语音识别只把转写文字放入输入框，不把音频发送给 DeepSeek，也不保存音频。
- 清除浏览器站点数据会删除本地任务；当前没有账号、云同步或跨设备恢复。
- 分享只包含学习报告，不包含原始材料和完整聊天。

- 约 5 MB DOCX、28 万中文字符的真实模型容量测试在 142.1 秒完成完整知识地图和首问，满足 180 秒上界；
- 六份材料的逐份耗时、真实对话和报告全文见 `docs/acceptance/六份材料真实链路验收.md`；
- 桌面 1440×900、平板 1024×768、手机 390×844 和横屏 844×390 已检查；
- 生产依赖与完整依赖树审计均为 0 漏洞，客户端静态分块未发现密钥、上游端点或系统提示词。

## 当前限制

- 只支持本地单用户运行，不应直接暴露到公网。
- 历史只在同一浏览器和设备恢复；没有账号、云同步或多人协作。
- 一项任务只接收一个文件；不支持旧版 Office、多文件合并和用户手动编辑知识地图。
- 5 MB / 30 万字符 / 3 分钟承诺只覆盖文本型 PDF、DOCX、PPTX；扫描 PDF 与图片的 OCR 耗时取决于页数和本机性能。
- 已完成主题可回看但不能重做四层或改分。
- 语音能力取决于浏览器和系统权限；不可用时仍可完整使用文字输入。
- Benchmark、AI Judge、完整游戏化、复杂知识图谱和公网部署留到后续任务。
