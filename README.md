# Veritas / 你真的理解吗

Veritas 是一个材料驱动的「诊断驱动学习」工具。你上传学习材料（PDF、Word、PPT、Markdown 等），它会挑出值得检验的知识点，先通过分层追问定位盲点，再像家教一样引导你把没懂的地方真正学会。

和刷题不同，题目不是预设好的，而是 AI 根据你的材料和你的每一句回答现场生成。判断你理解与否靠的是对话，而不是选择题对错。适合正在学习或已经学完材料、想查漏补缺的人，用于面试备考、考试复习和资格认证等场景。

## 它怎么工作

1. **从书架上传或选择材料**，AI 为每份材料挑出 1–15 个最值得检验的知识点。
2. **逐个知识点对话检验**，每个都从浅到深问四层：记忆→理解→应用→分析。答得上来才进下一层。
3. **不会可以索要提示或直接看答案**：用提示后答对照样算过；直接看答案则会被单独标记出来。
4. **全部检验完生成一份报告**，引用你自己说过的原话，指出具体盲点和下一步该做什么。

## 技术栈

Next.js（App Router）+ React + TypeScript + Tailwind CSS，AI 部分通过 OpenAI 兼容接口调用 DeepSeek，测试用 Vitest。
